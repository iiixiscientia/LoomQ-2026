## L2 交互体验

```text
启动界面或 CLI 的命令：
  Web 模式：cd starter_kit && python web_app.py
  CLI 模式：cd starter_kit && python web_app.py --cli
测试入口或页面地址：http://localhost:8765（启动后自动打开浏览器）
适合现场体验的 3 个用户任务：
1. 打开页面先走一段 13 页的绘本铺垫（改编自 Chris Ferrie《Quantum Information for Babies》
   的叙事节奏：一个球→球可以红/蓝→记录颜色要 bit→这是个电子/"量子球"→qubit 像彩虹一样
   同时是所有可能→bit 需求随量子位数指数增长→存一个分子的量子信息要地球上所有手机→
   量子系统才能做到），可随时点"跳过铺垫"直接进入实验；走完铺垫后轻触第一幕的小球几次——
   观察它"坍缩"成蓝色或红色并停在那个结果上，读懂气泡里"叠加/测量"的解释和 |0⟩/|1⟩ 记号
   跟颜色的对应关系；再进入第二幕轻触两颗球，观察它们总是同色，理解"纠缠"是什么。全程零
   文字输入，零 QASM 概念。
2. 第三幕"电路实验室"：三个盲盒排成一排，点一下＝施加 H 门（"叠加"），点亮盲盒之间的连接
   钮＝施加 CX 门（"纠缠"）——旁边的代码面板实时同步生成对应的 QASM 文本，把"拖玩具"和
   "写代码"两件事显式对应起来。搭出 h q[0]; cx q[0],q[1]; cx q[1],q[2]; 之后点"运行"，
   弹出一个"选后端"卡片组（文案直接取自 backend_capabilities.json：本地模拟器 vs 量旋云
   真机 vs 本源悟空真机，标注比特上限/排队/是否需要账号），选一个之后展示测量结果柱状图和
   一个当场算出来的 Hellinger 保真度数字（不是摆设——从本地精确模拟器的理想分布里做 256
   次有限抽样再计算，数值会因抽样次数产生真实涨落，呼应官方 L1 评测"shots=8192、
   Fidelity≥0.97"的同一套判定逻辑）。
3. 走完电路实验室解锁输入框后，点击"量子纠缠"卡片，体验 Agent 自动写贝尔态 QASM、本地
   模拟器自验、页面实时渲染测量结果柱状图；或在输入框粘贴 "这段代码有错误，帮我修好：
   H q[0]; CX q[0] q[1];"，观察 Agent 识别语法错误（未声明寄存器、门名大小写）、自动修复、
   自验通过的全过程。
截图或演示视频：（评委现场运行即可）
```

运行前需要 export LOOMQ_LLM_* 环境变量。Web 界面零额外依赖（纯 Python 标准库）。

首屏不是空白输入框，而是"绘本铺垫 + 两幕小球实验"的引导流程，视觉上做成暖色纸感背景
+ 黑色圆角仪表盘面板（蓝/棕/红三色点缀，参考硬件合成器/调音台面板的美术语言，而不是屏幕
发光的 HUD 风格）：绘本铺垫用小球/电子/手机/分子等原创图标讲完"为什么需要量子计算"的
直觉铺垫；第一幕一个轻轻旋转的彩虹小球，轻触后"坍缩"成蓝色或红色并停留在结果上，气泡文字
用大白话解释叠加与测量，并明确把 |0⟩/|1⟩ 记号翻译成"蓝/红的另一个名字"，同步展示真实的态
矢量记号（如 `a|0⟩+b|1⟩, |a|²=|b|²=0.5`）；连续触发几次后会用"大数定律"解释为什么采样比例
不会正好一半一半；第二幕出现第二个信号源，两者之间有一条常驻的"数据链"细线，轻触后两者总是
同步坍缩并停在同色上，展示贝尔态公式 `(|00⟩+|11⟩)/√2`，文案特别澄清"这不是瞬间传信号，是
关联"，避免强化常见的物理误解；第三幕"电路实验室"让用户亲手用盲盒+连接钮拼出一个真实电路
（GHZ-3：h q[0]; cx q[0],q[1]; cx q[1],q[2];，正是官方 L1/L2 测试用的同款电路），代码面板
实时同步生成对应 QASM 文本，运行时弹出取自 backend_capabilities.json 的选后端卡片，结果展示
真实计算出的测量分布和 Hellinger 保真度；走完三幕后才浮现输入框，进入自由对话（原有三张
建议卡片 + agent_chat 自然语言交互）。绘本、前两幕的坍缩结果、以及电路实验室的运行结果都
不是预设动画——统一由前端向 /api/simulate 请求本地精确态矢量模拟器算出的真实分布，再做
（加权）随机抽样得到具体结果，因此**不占用 LLM 调用预算、也不需要配置 DeepSeek key 就能
体验前三幕**，只有第四幕的自由问答才会调用 agent_chat。自由对话阶段 agent 返回的电路自动
渲染测量结果柱状图（Chart.js CDN），关键量子概念（纠缠/叠加/GHZ）以概念卡片形式穿插解释。
CLI 模式（--cli）作为无浏览器环境的 fallback（不含电路实验室这类图形化环节）。

设计参考：视觉美学参考了硬件合成器/调音台一类的实体仪表盘面板（黑色圆角面板、线条感旋钮/
表头、扁平药丸徽标），叙事节奏借鉴 Chris Ferrie《Quantum Information for Babies》绘本用
"一个球"贯穿始终讲清 bit→qubit→指数级信息量的直觉，以及 Kitty Yeung 的量子计算科普漫画
"图 + 真实公式 + 一句话人话"三件套的教学法：绝不用动画糊弄公式，每一步展示的数字和 ket
记号都来自本地模拟器算出的真实结果，且反复检查过 ket 记号在首次出现时是否已经用颜色词
翻译给零基础用户。

工作人员会在组委会统一模型环境中运行最终代码，测试新手是否看得懂、出错后能否得到有效帮助、结果是否清楚，以及多轮回答是否一致。选手自己的对话截图只用于说明产品流程，不直接证明得分。

## 工程与产品化

已有内容可以直接引用主 README 或其他项目文档，不必复制到本目录。

```text
干净环境中的构建和启动命令：
  见 starter_kit/README.md「快速开始」一节，核心命令：
    python3 tests/smoke_test.py                 # parser+codegen 自测，不需要任何 SDK
    python3 evaluator.py --target originq,braket  # 官方公开自测（L1）
    python3 tests/gate_coverage_test.py          # 12 门白名单覆盖测试（自建）
    python3 tests/hybrid_compiler_test.py        # L3 混合编译穷举测试（自建，9 例全过）
    python3 evaluator.py --level l3              # 官方 L3 公开自测
    python web_app.py                            # L2 Web 入口，浏览器自动打开 localhost:8765
  Dockerfile 提供了组委会基线容器 + spinq_env 构建步骤，干净环境按它一条命令即可跑通。

架构说明：starter_kit/README.md 顶部「目录结构」+ 各小节已完整覆盖。核心分层：
  QASM2 文本 -> src/qasm_parser.py 解析成 src/ir.py 的 Circuit
             -> src/codegen.py 按目标生成原生格式（transpile() 的返回值）
             -> src/backends/*.py 执行并规范化为统一 Schema（run() 的返回值）
  三个后端（spinq/originq/braket）共用同一份 parser+IR，只有"生成原生格式"和
  "调用哪个 SDK 执行"是平台相关的——这是评委要审查的"是不是真的通用"那条。
  L2（src/agent/）复用同一个 qasm_parser + reference_simulator 做自验，不占
  用 LLM 调用预算。L3（src/hybrid_compiler.py）是独立的小型编译器：tokenizer
  -> 递归下降 parser -> 生成 RISC-V 汇编，寄存器分配策略见该文件顶部注释。

目标用户和使用场景：
  面向"有具体问题意识、但没有量子物理或 QASM 背景"的跨界创作者/研究者/学生
  ——比如想验证一个化学分子的量子行为、但从没写过一行量子代码的人。使用场景
  是 web_app.py 的四幕流程：绘本铺垫建立"经典 bit vs 量子 qubit"的直觉 ->
  两幕点击式实验亲手感受"叠加"和"纠缠" -> 电路实验室用盲盒+连线拼出真实电路
  并实时看到对应 QASM -> 交给 Agent 用自然语言代劳（生成/纠错/选后端），全程
  不要求用户读懂任何一行代码也能走完整个流程。

完整使用流程：见「L2 交互体验」一节的 3 个用户任务描述；CLI 模式（--cli）
是无浏览器环境下的降级方案。
```

工作人员会按最终 commit 实际构建和启动，并检查文档与代码是否一致、产品是否真的降低了量子计算的使用门槛。

**必答题：你的工具让哪一类原本进不来的人，第一次能用上量子计算？**

没有物理或计算机科学科班背景、但有具体创作/研究问题意识的人——比如插画师、
音乐人、生物或化学专业但没学过量子力学的研究者。传统路径要求他们先学会
Dirac 记号、线性代数、至少一种量子 SDK 的方言（OriginIR/QCIS/各家私有
SDK）才能提交第一个电路。LoomQ 把这个门槛压缩成：看一段用"球的颜色"讲清楚
bit 和 qubit 区别的绘本、点几下鼠标感受"叠加"和"纠缠"、用盲盒拼一个真电路
（全程看着 QASM 代码同步生成，而不是凭空出现），最后一步不会写代码也没关系
——直接用中文告诉 Agent 想做什么，它会生成电路、自己验证、还能告诉你该去哪个
真实后端跑。三个量子云平台的方言差异被 L1 的统一中间层吸收掉，用户完全不需
要知道 OriginIR 和 QCIS 长什么样。

## 提交规则
